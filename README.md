## ✨ What Is This?

**Bingo Mixer** is an interactive, browser-based social bingo game where players mingle and find people who match fun prompts — first to get 5 in a row wins!

But it's also a **hands-on lab** that takes you through real-world GitHub Copilot Agent Mode workflows:

| 🎯 You'll practice… | 💡 By doing… |
|---|---|
| Context Engineering | Teaching the AI your codebase and coding style |
| Agentic Primitives | Building an AI-first engineering flow from scratch |
| Design-First Development | Letting AI iterate on UI while you guide the vision |
| Multi-Agent Development | Running parallel agents for TDD and design tasks |

## ⚡ Quick Start

### Prerequisites

- [Node.js 22+](https://nodejs.org/)
- [VS Code v1.113+](https://code.visualstudio.com/) with GitHub Copilot

### Option A — GitHub Codespaces *(recommended)*

Click **"Use this template"** → **"Open in a codespace"** and you're ready to go. The devcontainer sets everything up automatically.

### Option B — Local Dev

```bash
# 1. Clone your copy of the repo
git clone https://github.com/<your-username>/copilot-hands-on-bingo
cd copilot-hands-on-bingo

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) to see the app. 🎉

### Other Commands

```bash
npm run build   # Production build
npm run test    # Run tests
npm run lint    # Lint the codebase
```

> **GitHub Pages:** Every push to `main` automatically deploys to GitHub Pages via GitHub Actions.
